# Ecliptica Overlay

VRChatのログからEclipticaの戦闘情報を読み取り、デスクトップへ表示する
Windows向け補助オーバーレイです。

> 現在はベータ版です。EclipticaおよびVRChatの公式ツールではありません。

## 主な表示

- 現在の与ダメージ・被ダメージ
- 最大3種類の現在DPS
- 指定した直近時間内の最高単発ダメージ
- 指定した直近時間内の最高1秒ローリングDPS
- ボスのターゲット、フェーズ、トークン数、自己ベスト通知
- 戦闘履歴、クラス別記録、実績
- 日本語化したクラス名

最高単発と最高DPSの対象時間は、総合設定から1～60秒の範囲で変更できます。
ライトモードを選択しても、ゲーム上のオーバーレイは視認性を保つため
ダーク配色のまま表示されます。

## ダウンロードと起動

1. [Releases](https://github.com/ozpxxly/ecliptica-overlay/releases)から最新版の
   `Ecliptica-Overlay.exe` をダウンロードします。
2. 任意のフォルダーへ置き、ダブルクリックして起動します。
3. VRChatのログ監視を開始します。

Windowsの警告が出た場合は、ファイル名と配布元がこのリポジトリであることを
確認してから実行してください。

## 自動更新

起動時に1日1回、新しいバージョンを確認します。設定画面から手動確認や
自動確認の無効化もできます。更新ファイルはSHA-256で検証してから差し替えます。

初回の `v0.7.0-beta.1` だけは手動導入が必要です。

## データ保存先

設定、戦闘履歴、自己ベスト、クラス統計は次へ保存されます。

```text
%LOCALAPPDATA%\EclipticaOverlay
```

ソースコードと利用データを分離したため、Program Filesなどへ配置しても
データ保存が権限エラーになりにくい構成です。

## プライバシー

VRChatが端末内に出力したログをローカルで読み取ります。VRChatへのコード注入、
ログイン情報の収集、テレメトリー送信は行いません。更新確認時のみGitHubへ接続します。
